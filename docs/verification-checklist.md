# Verification Checklist

Use this checklist on every Canvas-to-CoEqual assignment run.

## Preflight

- [ ] Canvas URL captured.
- [ ] CoEqual course URL captured.
- [ ] Confirmed CoEqual course URL is the only stable default.
- [ ] Confirmed assignment details, rubric, course material, and setup fields will be dynamic for this run.
- [ ] Canvas policy set to read-only.
- [ ] CoEqual policy set to prepare and stop before final creation.
- [ ] Output/recovery location available.

## Canvas Action Gate

- [ ] Every Canvas action classified before execution.
- [ ] Action is clearly read-only.
- [ ] No Canvas form submission planned.
- [ ] No Canvas edit/save/post/publish/grade/upload/delete action planned.
- [ ] Risky Canvas controls avoided.

## Canvas Extraction

- [ ] Canvas page loaded.
- [ ] Canvas page title recorded.
- [ ] Assignment title extracted.
- [ ] Overview/prompt extracted.
- [ ] Guidelines extracted.
- [ ] Submission instructions extracted.
- [ ] Due structure extracted if visible.
- [ ] Rubric opened through read-only view only.
- [ ] Rubric criteria extracted.
- [ ] Rating labels extracted.
- [ ] Rating descriptions extracted.
- [ ] Exact point values extracted.
- [ ] Rubric total calculated.
- [ ] Canvas was not edited.

## Course Material

- [ ] Directed material link identified, if present.
- [ ] Directed material accessed read-only, if available.
- [ ] Summary uses only source-supported content.
- [ ] Unsupported claims removed.
- [ ] Inaccessible material clearly labeled as unavailable.
- [ ] Course material does not become an answer key unless prompt requires it.

## Local Records

- [ ] Assignment requirements record created.
- [ ] Course material summary record created.
- [ ] QA checklist/decision log created.
- [ ] No student data included unless explicitly required.
- [ ] No local secrets, cookies, downloads, or grades included.

## CoEqual Setup

- [ ] Correct CoEqual course verified.
- [ ] Assignment title matches Canvas exactly.
- [ ] Total points match Canvas exactly.
- [ ] Cohort size selected from evidence or user preference.
- [ ] Level selected from course context.
- [ ] Subject type selected from assignment context.
- [ ] Assignment type selected from assignment context.
- [ ] Grading approach set to Absolute Standards unless user says otherwise.
- [ ] Grading style set to Generous when lenient grading requested.
- [ ] Borderline cases set to Benefit of the Doubt unless user says otherwise.
- [ ] All setup fields read back after entry.

## Rubric Mapping

- [ ] CoEqual dimensions equal Canvas criteria count.
- [ ] Default unrelated dimensions removed.
- [ ] Dimension names match Canvas criteria.
- [ ] Dimension max points match Canvas criteria.
- [ ] Level labels match Canvas ratings.
- [ ] Level descriptions match Canvas descriptions.
- [ ] Level point values match Canvas exactly.
- [ ] Decimal values preserved exactly when present.
- [ ] Rubric total matches Canvas total.
- [ ] No scores between rubric levels added.

## Instructor Notes

- [ ] Notes say to grade leniently but according to the rubric.
- [ ] Notes list exact allowed scores.
- [ ] Notes say final score is the sum of selected rubric ratings.
- [ ] Notes say not to invent missing work.
- [ ] Notes say not to treat benchmark as the only correct answer.
- [ ] Notes include assignment-specific expectations.
- [ ] Notes do not add unsupported requirements.

## Benchmark

- [ ] Generated benchmark reviewed.
- [ ] Unsupported details removed.
- [ ] Benchmark starts with "example, not required template" framing.
- [ ] Benchmark is source-grounded.
- [ ] Benchmark is flexible for open-ended responses.

## Final Gate

- [ ] Final QA summary prepared.
- [ ] Canvas integrity checked again.
- [ ] Decision log complete.
- [ ] Comprehensive error matrix checked for unresolved L2/L3 issues.
- [ ] User asked before final Create assignment.
- [ ] No final CoEqual creation without confirmation.
